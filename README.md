# 🕒 Digital Clock Project using Python ⏰

This project is a simple Digital Clock built using Python and Tkinter, designed to display the current time in hours, minutes, and seconds, updating every second. The graphical user interface (GUI) is clean, minimal, and user-friendly. The main objective is to demonstrate how Python’s built-in libraries can be used to build real-time GUI applications. This project helped enhance my skills in working with Tkinter, real-time functions, and basic GUI layout design. It serves as a great starting point for beginners looking to explore Python GUI development.
